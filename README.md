# ⚡ LifeOS Tracker — Твой Персональный Хаб Жизни (PWA)

Эстетичный, быстрый и модульный трекер привычек и глубоких метрик с интерфейсом в стиле **Bento Grid** и возможностью добавления своих модулей.

---

## 🚀 Как запустить локально прямо сейчас

```bash
# 1. Запустить сервер разработки
npm run dev
```

Открой в браузере: **http://localhost:3000**  
*(Если открыть с телефона в одной локальной Wi-Fi сети: `http://<IP_компьютера>:3000`)*.

---

## 📱 Как вынести на экран телефона (PWA)

Приложение уже полностью настроено как **Progressive Web App**:
* **На iPhone (Safari):**
  1. Открой ссылку в Safari.
  2. Нажми кнопку **«Поделиться»** (квадратик со стрелкой вверх внизу экрана).
  3. Выбери **«На экран "Домой"»** (Add to Home Screen).
* **На Android (Chrome):**
  1. Открой ссылку в Chrome.
  2. Нажми три точки в верхнем углу.
  3. Выбери **«Установить приложение»** или **«Добавить на главный экран»**.

## 🌐 100% Бесплатный деплой в интернет (Vercel)

Ты получишь постоянную публичную ссылку вида `https://my-lifeos.vercel.app`:

1. Инициализируй Git и отправь в свой GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial LifeOS release"
   # Создай пустой репозиторий на github.com и привяжи:
   git remote add origin https://github.com/твой-логин/lifeos-tracker.git
   git branch -M main
   git push -u origin main
   ```
2. Зайди на [vercel.com](https://vercel.com) (вход через GitHub в 1 клик).
3. Нажми **«Add New...» → «Project»**, выбери свой репозиторий `lifeos-tracker` и нажми **«Deploy»**.
4. Через 40 секунд сайт готов и доступен с любого устройства в мире! При каждом новом `git push` Vercel будет сам обновлять сайт за 20 секунд.

## 🧩 Включенные модули и возможности

* 🏋️ **Зал & Тело:**
  * Трекинг утреннего веса с графиком динамики за 7 дней.
  * Тренировочный дневник: подходы, вес, повторения, PR (личные рекорды).
  * Встроенный таймер отдыха между подходами (90 сек).
  * Мониторинг калорий и КБЖУ (белки/жиры/углеводы).
* 🖨️ **3D Печать:**
  * Склад катушек филамента с цветом, температурой сопла/стола и остатком в граммах.
  * Активная печать с прогрессом, себестоимостью и весом модели.
  * Очередь печати и напоминания об обслуживании.
* 💰 **Накопления:**
  * Копилки с целями и визуальными прогресс-барами.
  * Быстрое пополнение (+500 ₽, +1 000 ₽, +5 000 ₽) с конфетти!
* 📚 **Книги:**
  * Трекинг прочитанных страниц и скорости.
  * Кнопки быстрого добавления страниц (+10, +25, +50).
* 🇬🇧 **Английский:**
  * Ежедневная норма практики в минутах.
  * Банк изученных слов.
* 💼 **Учеба & Работа:**
  * Pomodoro фокус-таймер (25 мин работа / 5 мин отдых).
  * Чек-лист приоритетных задач дня.
* ➕ **Конструктор кастомных модулей:**
  * Кнопка `+ Модуль` позволяет создать любую сферу (Гитара, Медитация, Бег, Авто) с выбором иконки и темы.
* ⚡ **Quick Action Sheet:**
  * Кнопка `+` в хедере открывает шторку для мгновенной фиксации воды, веса или финансов в 1 тап.
